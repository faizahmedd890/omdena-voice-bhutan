# 🎤 Voice-First Public Service Assistant (Bhutan)

This project is part of the Omdena Local Chapter for Bhutan:
**“Voice-First Public Services: Exploring Agentic AI Solutions in Bhutan.”**

## 🚀 Overview

This prototype explores how conversational AI can simplify access to public services in Bhutan.

The current version is a **Streamlit-based chatbot** that:
- Accepts user queries
- Classifies intent (passport, CID, license, etc.)
- Generates simple step-by-step responses using an LLM

---

## 🧠 Features

- 💬 Chat-based interface using Streamlit
- 🧭 Basic intent classification
- 🤖 LLM integration via Groq (LLaMA 3.1)
- 🪶 Lightweight and fast prototype
- 🧵 Session-based chat memory

---

## 🏗️ Tech Stack

- Python
- Streamlit
- Groq API (LLaMA 3.1 model)
- GitHub for collaboration
