Day 3 — Basic Streamlit Chat UI (Dummy)
What We Did
We created a simple chat interface using Streamlit (without real AI logic)
The UI included:
A chat input box
Display of the user’s message
A dummy bot reply like “Hello”

This helped us confirm that the chat UI works correctly before connecting it to any LLM.

Note

For upcoming integration, we decided to use Mistral AI because it provides a free API tier for testing at this stage.

Learning Outcome

We learned the importance of building and testing the user interface first, before integrating the language model.
