# Limitations

## Overview

This is a Week 2 prototype for early validation. It is not a production government system or an official source of public-service information.

---

## Current Limitations

- No official Bhutan G2C or government API integration
- No retrieval from verified government documents yet
- No RAG or official citations
- Keyword-based routing only
- Voice input works best in English
- No Dzongkha STT/TTS yet
- No translation layer yet
- No user authentication
- No access to personal records or application status
- No production security, monitoring, or audit logs
- No formal evaluation dataset yet

---

## Should Not Be Used For

This prototype should not be used for:

- Official government decisions
- Legal, tax, medical, or immigration advice
- Final document requirements
- Real application submission
- Handling sensitive personal data

---

## Next Steps

- Add verified government documents
- Build a small RAG prototype
- Improve routing with LLM classification
- Research Dzongkha STT/TTS and translation options
- Add human handoff
- Create test cases for routing, voice, and answer quality

---

## Summary

The prototype is useful for demonstrating voice + chat interaction, department routing, and Team 2-style conversation flows, but it still needs official data, stronger evaluation, and production safeguards before real use.
